# Balanced P1/P2 feedback matrix v2

October 3, 2026. Exploratory rerun of the 24 already-used challenge instances.
This is not new held-out material or confirmatory registration.

Question: with identical thinking settings, explicit pre-output checks, visible
record validation, Jev consistency review and one correction, how do P1/P2 final
plans compare? Also describe whether observed explanation/payload contradictions
disappear in actual final objects. Without a self-check-only control this matrix
cannot isolate the causal contribution of external feedback or of Jev alone.

Use all cases in challenge-test-v1.json; no case selection by current outcome.
Cross the same cases with P1 ordinary guidance and P2 operational self-model
framing. Preserve original fixed histories. Both conditions receive the identical
pre-output instruction: deliberate in the separate thinking phase, evaluate
sources/revisions/permissions/constraints before answering, and include a concise
reason agreeing with the actual final fields. The final answer remains one JSON
object. The protocol makes reason required for deliverable acceptance; original
keyed payload correctness remains a separately reported endpoint.

All actor calls use the locked ornith-aq1.5:35b digest, thinking true, context
16384, generation cap 8192, temperature 0, seed 42, top_k 20, top_p 0.95.
Streaming records actual thinking-versus-answer chunk order. Missing thinking,
mixed first-phase chunks or thinking after answer output cannot satisfy the
pre-output gate. This measures observable serialization, not faithful private
computation or proof that a narrated check occurred. Code validates the actual
object again before acceptance. Truncations remain possible and count as failures.

Generate 48 initial answers. Review each candidate with code and at most two
Jev field/explanation judgments selected by the v2 runtime's deterministic rule.
Build 48 condition-matched correction conversations from the exact initial final
answer, original task and identical feedback construction. Never replay separate
thinking. Each receives code failures, authoritative visible rows and narrow
semantic review, plus one correction opportunity. Revalidate every corrected
candidate and review up to two selected fields again. No terminal actor/reviewer
judgment is repeated to seek a better answer. Missing reason is an explicit
deliverability failure, not a silent bypass of semantic coverage.

Runtime validation receives only original visible task text, family, actual
candidate and completion status. Do not send benchmark keys, checks or source_facts
to actor or Jev. Source-derived validation and keyed grading share low-level
predicates, so agreement cannot independently validate those predicates.

Use pinned omkt_payload_consistency v1, hash
3d4ee30843872289b08aee9c74e22cb65db405631b0fa6b06cc1ebe799623544. Batch at most
twelve items, disable caching and recover complete saved traces with exact item,
question and provider-state checks. Record concrete returned model and alias.
Semantic contradiction at reported confidence >=0.8 withholds acceptance; this
cutoff is provisional workload policy, not calibrated correctness. Jev cannot
override any deterministic failure. Semantic judgments cover only selected fields.

Freeze all collector, validator, reviewer, orchestrator, dataset, settings and
protocol sources before initial collection. Freeze exact shared histories and
correction feedback before correction calls. Initial order seed 20261013;
correction order seed 20261014. Model digest/backend must remain unchanged.

Bounds: 96 actor calls, at most 192 semantic judgments, 900-second absolute
actor transfer timeout, 7200 seconds for initial collection and 14400 seconds
accumulated actor request time across both stages. HTTP provider retries are
additional attempts to report. Known terminal length/order stops may resume only
untouched cells after review. Uncertain starts halt; no blind repeat. Use the
existing local model/server, no downloads or paid hosted generator.

Primary: final keyed complete-payload success, planned denominator 24 per condition.
Report paired P2/P1 wins/losses, all cases/families, initial versus final repairs
and regressions, incomplete cells, required-reason compliance, actual pre-output
ordering, original/final selected-field contradictions, accepted drafts, wrong
acceptances, correct plans withheld, tokens, latency and reviewer costs. Do not
reward withheld wrong plans as completed correct answers. Do not use self-reported
virtue, internal-sounding prose or a lack of observed harm as correctness evidence.

No significance or population-generalization claim: reused author-designed
instances cluster within six templates, with no independent human case review.
If initial/final performance has a ceiling, retain the result and develop new
moderately difficult material with adequate thinking rather than weakening the
reasoning configuration to create failures.
